# VEXTRUS CUBIT

AI-native construction takeoff, cost database, estimation and bidding. Bangladesh first; built to travel.

Everything in this repository is built from one document: **[the Bible](docs/specs/cubit.bible.xml)** (`docs/specs/cubit.bible.xml`, v2.0.0). Every normative statement carries a permanent id; the product is done when every `must` requirement carries green evidence.

This repository is built by **Vextrus Builder** ([vextrus/vextrus-builder](https://github.com/vextrus/vextrus-builder)) — an autonomous build engine that compiles the Bible into a whole-product increment graph and drives verified, gated, reviewed increments to `main`. Nothing in this repository runs a model; the Builder reaches in only through its gates.
